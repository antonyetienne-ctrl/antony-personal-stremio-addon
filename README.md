# Antony Personal Stremio Addon v5.2.0

Personal Stremio recommendations with a unified Films + Series taste model.

## Catalog visibility
- Films recommendations: configurable on/off.
- Series recommendations: configurable on/off.
- Optional separate **Films érotiques** catalog: non-personalized, popularity-sorted, minimum 15 minutes, and explicitly excludes pornographic/explicit-adult content.

The erotic catalog is independent from the recommendation engine and does not affect the learned taste profile.
